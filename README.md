# Let Report

A QC/QA trouble-report app for food production. Staff spot a problem, snap a photo and send it in two taps. QA, supervisors and the plant manager then hold products, assign fixes, escalate and close reports. It works in the browser on phones, tablets and computers, in English and Khmer.

## Folders

```
let-report/
├── README.md     this file
├── web/          the web app (source code, build script, ready-to-open dist/)
└── design/       the Claude Design handoff: prototypes, design system, original assets
```

| Folder | What it is | Start here |
|---|---|---|
| `web/` | The working app, built from the design | `web/README.md`, or open `web/dist/index.html` |
| `design/` | Source design from Claude Design (reference only, not edited) | `design/HANDOFF.md`, `design/Trouble Report App v2.dc.html` |

## Quick start

```bash
cd web
npm install
npm run dev
```

Or double-click `web/dist/index.html` to open the app without installing anything.
